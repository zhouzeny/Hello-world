# 社会痛点信息收集与统计分析平台

## 项目概述

本项目是一个面向社会大众的痛点信息线上收集平台，配套内部加密管理后台，用于对生活、工作、行业等各类社会痛点进行安全收集、自动整合、分类统计与可视化分析。

平台分为两端：
- 前台：面向普通用户的极简填报入口，无需注册即可提交痛点信息。
- 后台：面向授权管理员的加密管理与数据分析系统，负责分类、统计、图表展示和行业总结。

## 项目目标

- 便捷收集社会痛点信息，降低用户填报门槛。
- 全流程加密保护用户隐私与核心数据。
- 自动整理分散数据，提升管理效率。
- 通过图表和报告输出，支持民生优化与行业改进。

## 核心角色

- 普通填报用户
- 后台授权管理员
- 平台运维人员

## 核心功能

### 前台

- 痛点信息在线填报
- 场景选择与行业分类
- 痛点描述与联系方式选填
- 提交前基础校验
- 提交成功反馈

### 后台

- 加密登录与分级权限管理
- 痛点数据自动汇总
- 按痛点性质、行业维度分类
- 条形图、扇形图等可视化展示
- 行业痛点统计与总结报告生成
- 操作日志记录与审计

## 业务流程

1. 用户进入前台填报页面。
2. 选择痛点场景、行业并填写详细内容。
3. 系统完成校验后提交。
4. 数据加密传输并加密存储。
5. 后台解密后进行自动整合与分类。
6. 系统生成统计图表和行业总结。

## 安全设计

- 传输加密
- 存储加密
- 后台账号加密管理
- 权限分级控制
- 操作日志留痕
- 数据备份与恢复

## 建议技术方向

- 前端：React + Vite
- 后端：Spring Boot 3 + Java 17
- 数据库：MySQL 8
- 缓存：Redis
- 图表：ECharts
- 安全：HTTPS、密码哈希、字段加密、角色权限控制

- 前端：进入 `frontend` 后执行 `npm install`，再执行 `npm run dev`
- 后端：进入 `backend` 后执行 `mvn spring-boot:run`
